# Project Patchwork — 게임 기획서 v0.2

> 텍스트 UI 기반 턴제 덱빌딩 로그라이트. 플레이어는 네크로맨서, 전투 주체는 몬스터 부속으로 조립한 **누더기 골렘**.

---

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 플랫폼 | Web (HTML/CSS/JS, 빌드리스 or Vite) |
| 아트 | 이미지 에셋 최소화. 텍스트 + 유니코드 기호 + CSS만으로 표현 |
| 장르 | 턴제 전략 덱빌딩 로그라이트 / 파츠 크래프팅 |
| 1런 목표 시간 | 25~35분 (Act 1 기준 12~15분) |
| 핵심 판타지 | "적을 죽여 그 시체로 내 병기를 만든다" |

### 1.1 디자인 원칙 (판단 기준)
1. **모든 스탯 변화는 파츠에서 나온다.** 골렘 자체는 빈 프레임이며 고유 스탯이 없다. → 빌드 = 장착 조합.
2. **텍스트가 곧 피드백.** 전투 로그가 UI의 주인공. 수치 변화는 로그 문장에 녹여 쓴다.
3. **데이터 주도.** 몬스터/파츠/카드/이벤트는 전부 JSON. 코드 수정 없이 콘텐츠 추가 가능.
4. **모디파이어로 곱셈.** 파츠 40개 × 모디파이어 12개 = 체감 수백 종.

## 2. 코어 루프

```
분기맵 노드 선택
   ↓
전투 (턴제 카드 배틀)
   ↓
전리품: 쓰러진 몬스터의 부위 해체 → 파츠 1~3개 중 택1
   ↓
작업대: 골렘 슬롯에 장착 / 교체 / 해체(재료화)
   ↓  (장착 = 덱 구성 변경)
다음 노드 → ... → 보스
   ↓
사망 or 클리어 → 메타 재화 '영혼재(Soul Ash)' 정산 → 영구 해금
```

**핵심 긴장 구조:** 파츠를 교체하면 스탯은 오르지만 **덱에서 카드가 빠지고 새 카드가 들어온다.** 강한 팔을 끼웠는데 덱 시너지가 무너질 수 있다. 이것이 이 게임의 주요 의사결정이다.

## 3. 골렘 조립 시스템

### 3.1 슬롯 구성 (5슬롯)

| 슬롯 | 주 기여 스탯 | 카드 기여 | 비고 |
|---|---|---|---|
| 머리/코어 | 정신력(에너지), 통찰 | 0~1장 | 전투 시작 시 발동 패시브 |
| 몸통 | 최대 HP, 방어 | 1장 (방어계) | 유일하게 비울 수 없음 (필수 슬롯) |
| 좌완 | 공격력 | 1~2장 | 무기 속성 부여 |
| 우완 | 공격력 | 1~2장 | 무기 속성 부여 |
| 다리 | 회피, 속도 | 1장 | 선공 판정 / 유틸 |

- **빈 슬롯 허용** (몸통 제외). 빈 슬롯은 스탯 0, 카드 0 → 덱이 얇아져 핵심 카드 회전율이 올라가는 **의도적 전략**이 된다.
- 총 덱 크기 목표: **8~14장**. 얇은 덱이 정상. StS(15~35장)보다 훨씬 압축적.

### 3.2 스탯 산출식

```
maxHP    = Σ(파츠.hp)                        // 몸통이 60~70% 차지
attack   = Σ(파츠.atk)                        // 카드 데미지 계수에 곱해짐
defense  = Σ(파츠.def)                        // 방어 카드 획득 블록량에 가산
evasion  = min(60, Σ(파츠.eva))               // % 회피, 하드캡 60
speed    = Σ(파츠.spd)                        // 선공 판정 및 일부 카드 조건
energy   = 3 + Σ(파츠.energy)                 // 턴당 카드 사용 자원, 캡 6
```

데미지 공식:
```
최종피해 = floor( (카드기본값 + attack × 카드계수) × 속성배율 ) - 대상.block
```
`카드계수`는 보통 1.0, 다타 카드는 0.4~0.6.

### 3.3 내구도 (Integrity)

시체 부속이라는 컨셉을 기계적으로 살리는 장치.

- 모든 파츠는 `integrity` 3~8 보유.
- **전투 종료 시** 해당 전투에서 카드를 사용한 파츠는 내구도 -1.
- 내구도 0 → **부패(Rotten)**: 스탯 50%로 감소, 제공 카드에 `부패` 태그가 붙어 사용 시 골렘이 2 피해를 받음. 파괴되지는 않는다(빌드가 통째로 붕괴하면 재미없음).
- 회복 수단: 캠프파이어 노드, '방부 처리' 이벤트, 소모품 '역청(Bitumen)'.

> 설계 의도: 강력한 파츠를 아껴 쓰게 만들고, 캠프파이어 노드에 "회복 vs 수리" 선택 긴장을 만든다.

## 4. 모디파이어 시스템

몬스터에 부여된 접두사가 **드랍 파츠에 그대로 계승**된다.

```json
{
  "id": "mod_poison",
  "prefix": "독을 품은",
  "tier": 1,
  "stat_multiplier": { "hp": 0.8, "atk": 1.2 },
  "flat_bonus": {},
  "added_skill": "skill_poison_sting",
  "monster_passive": "on_hit_apply_poison_2",
  "weight": 100
}
```

### 4.1 모디파이어 풀 (v1 목표 12종)

| ID | 접두사 | 스탯 영향 | 부여 카드 / 효과 |
|---|---|---|---|
| mod_poison | 독을 품은 | hp×0.8 atk×1.2 | 독침 (중독 3 부여) |
| mod_giant | 거대한 | hp×1.5 spd×0.7 | 짓누르기 (고데미지·2에너지) |
| mod_swift | 재빠른 | eva+8 spd×1.5 hp×0.85 | 잔상 (회피 1스택) |
| mod_burning | 불타는 | atk×1.15 | 발화 (화상 2) |
| mod_frozen | 얼어붙은 | def×1.3 spd×0.8 | 서리 (적 에너지 -1) |
| mod_rotting | 썩어가는 | hp×1.2 integrity×0.5 | 역병 구름 (광역 중독) |
| mod_armored | 강철갑주의 | def×1.6 eva×0.5 | 경화 (블록 유지) |
| mod_frenzied | 광란의 | atk×1.4 def×0.6 | 난도질 (3연타) |
| mod_ancient | 고대의 | 전스탯×1.25 | (희귀) 랜덤 스킬 1 |
| mod_hollow | 텅 빈 | hp×0.6 energy+1 | — |
| mod_vampiric | 흡혈하는 | atk×1.1 | 갈증 (피해량의 50% 회복) |
| mod_thorned | 가시돋친 | def×1.2 | 가시 (반사 3) |

### 4.2 적용 규칙
- Act 1: 일반 몬스터 40% 확률로 모디파이어 1개 (tier 1만).
- 엘리트: 100%, 1~2개. 보스: 고정 세트.
- 층이 깊어질수록 tier 2 해금, 최대 2개 중첩 (`거대한 불타는 오우거의 팔`).
- 스탯 배율은 **곱연산 후 반올림**, 중첩 시 순차 적용.

### 4.3 동적 네이밍
```
[모디파이어 접두사] + [몬스터 소유격] + [부위]
"독을 품은" + "고블린의" + "다리"
```
데이터에는 `{mod}{owner}{part}` 템플릿만 저장하고 런타임 조립.

## 5. 전투 시스템

### 5.1 턴 구조
```
전투 시작 → 코어 패시브 발동 → (speed 비교로 선공 결정)
반복 {
  플레이어 턴:
    에너지 회복(=energy 스탯) / 블록 소멸 / 손패 5장 드로우
    카드 사용 (에너지 소모) → 자유 종료
    턴 종료 시: 손패 전부 버림, 상태이상 틱
  적 턴:
    의도(Intent) 실행 → 다음 의도 공개
}
→ 한쪽 HP 0
```

- **의도 공개**: 적 이름 옆에 `⚔18` `🛡12` `☠중독` 형태로 다음 행동 표시. StS와 동일하게 정보 공개형.
- 덱 소진 시 버린 더미를 셔플하여 재사용.

### 5.2 카드 타입
| 타입 | 설명 |
|---|---|
| 공격 | 피해. `atk` 스탯 스케일. |
| 방어 | `block` 획득. `def` 스탯 가산. 턴 시작 시 소멸(일부 예외). |
| 술수 | 상태이상, 드로우, 에너지, 특수. |
| 파워 | 전투 내내 지속. 코어 파츠에서만 등장. |
| 부패 | 내구도 0 파츠가 제공. 사용 시 자해 2. |

### 5.3 상태이상 (v1 8종)
| 이름 | 효과 |
|---|---|
| 중독 | 턴 종료 시 스택만큼 피해, 스택 -1 |
| 화상 | 턴 종료 시 스택만큼 피해, 스택 유지(해제 필요) |
| 취약 | 받는 피해 +50%, 턴당 -1 |
| 약화 | 주는 피해 -25%, 턴당 -1 |
| 힘 | 공격 피해 +스택 |
| 민첩 | 블록 획득 +스택 |
| 재생 | 턴 종료 시 회복 |
| 가시 | 피격 시 반사 피해 |

### 5.4 전투 텍스트 로그
모든 행동은 로그 라인으로 출력. 랜덤 동사 풀로 반복감 완화.
```
> 골렘이 [녹슨 도끼팔]을 휘두른다. 고블린이 14의 피해를 입는다.
> 독을 품은 고블린의 송곳니가 골렘의 이음새를 파고든다. (9 피해, 중독 2)
> 고블린이 쓰러진다. 남은 것은 아직 경련하는 다리 한 쌍.
```

## 6. 맵 & 진행

### 6.1 구조
- Act 1 = **12층**, 각 층 2~4개 노드, StS식 분기 연결.
- 노드 타입: 전투(⚔) / 엘리트(☠) / 이벤트(?) / 작업대(🔨) / 캠프파이어(🔥) / 보스(👑)

### 6.2 Act 1 층 배치 규칙
```
1층    : 전투 고정
2~3층  : 전투 (모디파이어 확률 진입)
4층    : 이벤트 or 작업대
5층    : 엘리트 최소 1개 보장
6층    : 캠프파이어
7~9층  : 혼합 (전투 40%, 이벤트 25%, 엘리트 15%, 작업대 20%)
10층   : 엘리트
11층   : 캠프파이어 (보스 전 정비)
12층   : 보스
```
- 동일 층에서 같은 타입 노드 3연속 금지.
- 캠프파이어 직전 층에는 전투 노드 보장(회복 자원이 의미 있도록).

### 6.3 캠프파이어 선택지
1. **휴식** — 최대 HP의 30% 회복
2. **수리** — 파츠 1개 내구도 완전 회복
3. **개조** — 파츠 1개에 모디파이어 랜덤 부여 (기존 것 덮어씀, 도박)

## 8. 메타 진행 (로그라이트)

- 재화: **영혼재(Soul Ash)** — 층수 + 처치 엘리트/보스 기준 정산.
- 해금 항목:
  1. 신규 파츠 풀 추가 (런 중 등장 확률 진입)
  2. 시작 골렘 프리셋 (초기 장착 3종)
  3. 모디파이어 tier 2 조기 해금
  4. 유물 슬롯 (Act 2 이후)
- **표본 보존**: 클리어/사망 시 파츠 1개를 표본실에 저장 → 다음 런 시작 시 장착 상태로 시작 (내구도는 절반).

## 9. 데이터 스키마

```jsonc
// parts.json
{
  "id": "part_arm_goblin_claw",
  "name_template": "{mod}{owner} 발톱팔",
  "slot": "arm",            // head | body | arm | leg
  "rarity": "common",
  "stats": { "hp": 0, "atk": 5, "def": 0, "eva": 2, "spd": 3, "energy": 0 },
  "integrity": 5,
  "cards": ["card_claw_swipe", "card_rend"],
  "passive": null,
  "drop_from": ["m_goblin"]
}

// cards.json
{
  "id": "card_claw_swipe",
  "name": "발톱 후려치기",
  "type": "attack",         // attack | skill | power | curse
  "cost": 1,
  "base": 6,
  "atk_scale": 1.0,
  "hits": 1,
  "effects": [{ "op": "damage" }],
  "text": "{target}에게 {dmg}의 피해."
}

// monsters.json
{
  "id": "m_goblin",
  "name": "시궁쥐 고블린",
  "tier": "normal",
  "hp": 28,
  "acts": [1],
  "intents": [
    { "id": "slash", "type": "attack", "value": 7, "weight": 60 },
    { "id": "double", "type": "attack", "value": 4, "hits": 2, "weight": 25 },
    { "id": "guard", "type": "block", "value": 8, "weight": 15 }
  ],
  "intent_rules": { "no_repeat_over": 2 },
  "drops": ["part_arm_goblin_claw", "part_leg_goblin_hop"]
}
```

`{mod}` 자리에 모디파이어 접두사가 런타임 삽입되고, 없으면 빈 문자열로 치환된다.

- 카드 선택은 클릭 + 숫자키 단축키 병행.

## 13. 미결 사항 (결정 필요)

1. **전투 조작 방식** — 위 설계는 *카드 드로우형(StS)*. 대안은 *스킬 쿨다운형*(손패 없이 파츠 스킬을 쿨다운으로 사용). 후자가 구현은 단순하지만 매 전투 변주가 줄어든다. → **현재 안: 카드 드로우형**
2. **내구도 강도** — 현재는 "부패해도 파괴되지 않음". 파괴형으로 가면 파밍 압박이 커진다.
3. **골렘 사망 = 런 종료 여부** — 대안: 골렘 파괴 시 몸통만 남기고 계속(2번의 기회). 로그라이트 관대함 조절 레버.
4. **언어** — 텍스트가 핵심이므로 한국어 전용으로 갈지, i18n 구조를 처음부터 넣을지.
